# Project Statement: Railway Ticket Booking System

## Problem statement

Passengers need a way to find train information and manage ticket bookings. This project demonstrates a simple menu-based program for performing these tasks.

## Scope

The project provides a command-line demonstration of train search, ticket booking, fare calculation, booking lookup, and cancellation. It uses a predefined train list and saves booking records in a local text file.

This is an educational project. It does not connect to a real railway reservation service or process online payments.

## Target users

- Students learning Python programming
- Users demonstrating basic ticket-booking workflows

## High-level features

- View train routes, schedules, distances, and available seats
- Search for a train by its starting point and destination
- Book tickets and calculate fares by travel class
- View bookings and check a booking using its PNR
- Cancel a booking and calculate the refund
